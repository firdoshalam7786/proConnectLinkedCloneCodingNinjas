# 🚀 ProConnect – LinkedIn Clone

A modern full-stack professional networking platform inspired by LinkedIn.  
Built to help users connect, share posts, and interact in a clean and responsive social experience.

---

## 🌐 Live Demo
🔗 https://pro-connect-linked-clone-coding-nin.vercel.app/

## 💻 GitHub Repository

---

# ✨ Features

✔️ Secure Authentication with JWT  
✔️ Create & Update User Profiles  
✔️ Create, Edit & Delete Posts  
✔️ Like & Comment on Posts  
✔️ Send & Accept Connection Requests  
✔️ Discover New Users  
✔️ Fully Responsive Design  

---

# 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Redux
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)

### Authentication
- JWT (JSON Web Token)
